## 开发前必须确认但不阻塞建模的事项

1. 若依后端真实仓库路径和当前分支。
2. 当前数据库类型与版本。
3. 文件最终落本地磁盘、COS、OSS 还是其他对象存储。
4. 小鹅通已有 SDK/客户端和测试环境凭据由谁提供。
5. 现有学生、课程和 `/auth/*` 数据表是否已经在线使用。

若这些信息暂时缺失，开发 thread 可以先完成表结构对照、接口骨架设计和纯业务单元测试，但不得凭空创建第二套认证主数据。
