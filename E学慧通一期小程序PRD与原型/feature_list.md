# E学慧通第一期小程序与后台端 Feature List

> 范围依据：小程序第一期功能以 `prototype.html` 为准；后台端以 `admin_prototype.html` 为准。后台仅保留账号管理、内容配置、数据中心、同步日志四个一级模块；项目路线图仅作为背景材料，不作为本版需求边界判断依据。

## 优先级定义

| 优先级 | 含义 | 本文口径 |
| --- | --- | --- |
| P0 | 第一期必须具备，当前原型中主流程已明确 | 一期验收功能 |
| P1 | 第一期重要增强，当前原型中已有页面或状态表达 | 一期建议完成，可灰度 |
| P2 | 辅助体验、运营配置或实现细节优化 | 不影响核心体验闭环 |

## 完整性检查

| 检查项 | 结论 | 处理 |
| --- | --- | --- |
| 原型中作业提交是否为一期？ | 是 | 纳入 P0：任务列表、提交页、图片、备注、确认提交 |
| 原型中学情档案是否为一期？ | 是 | 纳入 P0：我的页摘要、报告页详情、作业表现、课程观看 |
| 游客是否能直接看作业？ | 否 | 通过绑定拦截和 Toast 提示控制 |
| 未绑定用户是否有明确下一步？ | 是 | 首页、作业、我的均有绑定入口 |
| 课程是否只做列表？ | 否 | 需支持预约、观看、服务号提醒说明和公益课推荐弹窗 |
| 小程序是否直接接第三方课程/作业？ | 否 | 小程序只调我们平台，第三方由后台配置和后端转发 |
| 第三方是否保存主数据？ | 否 | 第三方只提供功能，所有业务数据统一落在我们平台 |
| 账号导入和学生绑定在哪里完成？ | 后台端 | 由我们运营/教务在后台导入、校验、绑定、处理冲突 |
| 内容创建是否在一级页平铺？ | 否 | 一级页只展示用户端和模块；创建、配置、上架都在二级资源列表完成 |
| 课程和文件是否必须同时存在？ | 否 | 课程和文件可关联，也可分别独立存在 |
| 数据落库是否还是一级模块？ | 否 | 已变更为数据中心下的子模块 |
| 教师端是否可点击？ | 是 | 教师端首页、班级、我的和入口级操作均需有反馈 |
| 是否依赖路线图判断阶段？ | 否 | 本版以当前交互原型为验收基准 |
